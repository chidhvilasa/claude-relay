# Sharing Claude Relay

Copy-pasteable information for recommending Claude Relay to another developer.

**Name:** Claude Relay

**One-liner:** Session continuity, recovery, checkpoints, and handoffs for Claude Code.

**Install (VS Code):**
Search `Claude Relay` in the Extensions view, or install directly:
```
code --install-extension clauderelay-oss.claude-relay
```
Publisher: `clauderelay-oss`. Extension ID: `clauderelay-oss.claude-relay`.

**Install (Claude Code Plugin — automatic protection):**
```
claude plugin marketplace add chidhvilasa/claude-relay
claude plugin install claude-relay@clauderelay-oss
```

**GitHub:** [chidhvilasa/claude-relay](https://github.com/chidhvilasa/claude-relay)

**Security summary:** no OAuth, no Claude credential access, no runtime network access, no automatic Git
mutation — see `docs/HOW_CLAUDE_RELAY_WORKS.md` for the full account.

**Independence:** Claude Relay is an independent open-source project and is not affiliated with or
endorsed by Anthropic.
